# Semana 14

Este proyecto calcula el área de un rectángulo.

## Cómo usar

1. Ejecuta el archivo `Semana 14.py`.
2. Ingresa la base del rectángulo.
3. Ingresa la altura del rectángulo.
4. El programa mostrará el área calculada.

## Fórmula

Área = base × altura

Ejemplo:
- base = 5
- altura = 3
- área = 15
