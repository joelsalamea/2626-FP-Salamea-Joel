# Semana 13 - Área de un rectángulo

Descripción

Este ejercicio contiene una función para calcular el área de un rectángulo. El script permite ingresar por teclado la base y la altura y muestra el resultado.

Archivos

- ejercicio_semana13.py: Implementación de la función calcular_area_rectangulo y prompts de entrada.

Requisitos

- Python 3.x

Uso

Desde la raíz del repositorio ejecutar:

python "Semana 13\ejercicio_semana13.py"

Ingrese la base y la altura cuando se solicite (números reales). El programa validará entradas no numéricas.
