# Semana 15 - Colecciones de datos

## Descripción
Este proyecto desarrolla un programa sencillo para registrar y gestionar las notas de los estudiantes de la Unidad Educativa Ayapamba. Se utiliza un diccionario para relacionar cada nombre de estudiante con su respectiva nota.

## Objetivo
Aplicar el uso de colecciones de datos con estructuras como listas, conjuntos y diccionarios para resolver un problema de la vida real.

## Funcionalidades
- Agregar estudiantes y notas.
- Mostrar toda la información almacenada.
- Buscar un estudiante en específico.
- Actualizar la nota de un estudiante.
- Eliminar registros.
- Calcular el promedio general de notas.

## Estructura utilizada
El programa principal trabaja con un diccionario en Python:

```python
estudiantes = {
    "Ana": 9.5,
    "Luis": 8.7,
    "Mateo": 7.8,
    "Sofía": 9.1,
}
```

## Cómo ejecutar
1. Abre una terminal.
2. Dirígete a la carpeta `Semana 15`.
3. Ejecuta el siguiente comando:

```bash
python ejercicio-colecciones.py
```

## Ejemplo de uso
Al ejecutar el programa, se mostrará un menú con diferentes opciones. Puedes elegir ingresar nuevos estudiantes, buscar un registro o calcular el promedio de notas.
