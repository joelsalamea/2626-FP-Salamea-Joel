Objetivo:
El programa permite reservar una butaca en una sala de cine representada como una matriz de 3 filas por 4 columnas. Al ejecutarse solicita una única fila (0-2) y una única columna (0-3), registra la reserva marcando la butaca con 1 y muestra la sala completa como una tabla de ceros y unos.

Requisitos:
- Python 3

Cómo ejecutar:
1. Abrir una terminal en la raíz del proyecto.
2. Ejecutar el siguiente comando:

   python "Semana 12\reserva_cine.py"

3. Ingresar la fila (0-2) y la columna (0-3) cuando se solicite.
4. El programa mostrará si la reserva se realizó o si la butaca ya estaba ocupada, y luego imprimirá la sala completa como una tabla de 3 filas por 4 columnas con 0s y 1s.

Ejemplo de comportamiento:
- Entrada: fila 1, columna 2
- Salida: mensaje de "Butaca en fila 1, columna 2 reservada." y la matriz con un 1 en la posición indicada.

Notas:
- Las filas y columnas se ingresan en formato 0-based (comienzan en 0).
